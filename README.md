# Capital Guardian

Pivoton is the platform of the AI-driven capital protection legit financial investment platform with no fee on profitable trade

Here below are some main features in brief (please aware to enable function applying credit/debit card for any in-app transaction in need)

1. Subscription based model: Any user can pay for a premium package to unlock premium features in a duration of cycle. Premium investors can access statistical tools to capture previous recording history of recommendation from certified stock brokers, the AI agent chatbot to communicate and consult for more information of stock trading with all the relevant topic of Q&A from Finance field. Premium users can access working dashboard with AI tools to help analyze stock and compose content automatically when create post/article or explanation for recommendation from private room chat.

2. Broker's consultancy fee. Brokers can configure multiple chargeable private chat rooms. Any user can pay for these private chat room memberships to get updates from VIP investing information with some special method of recommendation. Premium users can access analytic tool to track all records from these recommendations and call brokers for live consultancy during their trading session). Any profile page in which the user being as stock broker can update their job title and upload their broker license as Securities Industry Essentials (SIE), General Securities Representative Qualification Examination (Series 7), Uniform Securities Agent State Law Examination (Series 63), Investment Adviser Representative (IAR- Series 65) (there is the box to tick as whether the user is a stock broker  and the information will be displayed in need to choose from the drop down list box the correct license type to upload for KYC verification from one belong to these license: Securities Industry Essentials (SIE), General Securities Representative Qualification Examination (Series 7), Uniform Securities Agent State Law Examination (Series 63), Investment Adviser Representative (IAR- Series 65),

)





3. Safe investment marketplace:

a. Brokazy’s AI system will filter, verify to display recommendations heated from other stock

brokerage firms prior one trading day to let user will prepare money to deposit (these are

called rumors with hided stock/ETF code name, only visible to trade graph view/ all

indexes. User can directly fund in Brokazy's wallet and deposit to purchase a limit

amount of recommended guaranteed ETF/stock). Be aware that user should pay

insurance fee of 3% for any loss trade in guarantee (There is a correct term in description to state user about this fee required to pay in loss case with the max amount of insurance fee to charge is 3%, user does not need to pay in win trade case). 





4. Affiliation shopping marketplace:

a. Affiliate all trading gateway from certified brokerage firm (we do not intend to build us as a

trading platform but to integrate all other available trading gateway inside Brokazy's

platform)

b. Affiliate for in-app spending incorporated with all 3rd party service provider

(Ecommerce/Delivery/Edtech/Car/Real estate) with an overlay tag of provider name on

item. This is designed with a screen as shopping marketplace

c. Applicable for payment on POS/NFC: User could use Brokazy's loan for spending at

offline store via POS payment service, NFC, etc. (Think out some way to earn revenue

Loan insurance fee: A page where offering the accessible margin loan up-to 1 month salary with the verification step to request uploading all necessary documents for KYC steps of ID card, face scanning, labor contract to ensure the employment status.
